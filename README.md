## ✨ Fitur Utama
- **Mode Mobile & Desktop Windows**: Beralih antara tampilan peramban HP biasa atau Chrome Desktop Windows 10/11 (User-Agent resmi, viewport 1280px, popup login OAuth Google/Microsoft/Facebook).
- **Sesi Tetap Hidup di Latar Belakang**: Saat kembali ke Beranda, situs dan media tidak di-reload atau dimatikan.
- **Isolasi Multi-Profil**: Cookie, sesi login, dan cache setiap tombol terpisah satu sama lain.
- **Kiosk Layar Penuh Imersif**: Bebas bilah alamat dengan pegangan menu vertikal tetap di tepi kiri layar.
- **Penyimpanan Lokal Penuh**: Berbasis Room Database, tanpa akun dan tanpa server eksternal.
